## 详细改动

- 北京 09:00 补前一交易日、15:00 抓当日暂定版；休市跳过，未知年份拒绝采集。
- 上午板块须在 09:15 前完成；优先板块后指数，避免数字对象键排序抢占补采窗口。
- 同供应商串行间隔 10–20 秒，20 秒超时，最多 3 次尝试，60 / 180 秒退避加抖动。
- 尊重 Retry-After；拒绝访问或持续限流停止该源本轮请求。
- 板块与资金同次分页采集；校验源日期、total、重复与数值，修正 fltt=2 再除100的问题。
- 腾讯 → 新浪 → 东方财富指数降级；由日线聚合周线，移除分时采集和展示。
- schemaVersion=2 保存真实数据日期、批次、来源与暂定/补采标记；成交量不冒充统一单位。
- 关联组完整写入后发布，失败回滚保留旧值；运行中状态阻止半成品部署。
- 发布门禁兼容完整旧格式组；旧格式与新格式混组拒绝发布。
- 前端只读静态 JSON；修复缓存封装及切换竞态，洞察拒绝日期/批次不一致的合并。
- 资金占比缺失显示破折号，不以零冒充；错误时显示旧值提示。
- 采集工作流显式调用 Pages 工作流并固定提交 SHA；部分失败仍可部署安全旧值及失败状态。
